# Welcome to handmedown

This card is a markdown file. Every card on the board is a file from your
notes folder, so anything you write in plain `.md` shows up here.

- **Tap** (a quick pinch) opens and closes things.
- **Pinch and drag** to move a card.
- **Flick** while you let go to throw it.
- **Pinch with both hands** on one card and pull apart to resize it.

Tap the ring at the bottom any time to fold everything away.
